# EVOLVE 2.0 — Flutter MVP

نسخه اول قابل توسعه از اپلیکیشن رشد فردی و یادگیری چندبعدی.

## امکانات پیاده‌سازی‌شده
- داشبورد فارسی و راست‌چین با تم تیره
- برنامه روزانه ۷ بخشی و ثبت انجام تمرین‌ها
- مسیر آموزشی ۱۲ ماهه
- ژورنال روزانه با ذخیره محلی
- صفحه پیشرفت و شاخص‌های پایه
- صفحه مربی هوشمند با اتصال به یک endpoint امن قابل تنظیم
- نگهداری داده‌ها روی دستگاه با SharedPreferences

## نیازمندی‌ها
- Flutter SDK (نسخه پایدار جدید)
- Android SDK و Android Studio یا command-line tools
- اتصال اینترنت برای دریافت پکیج‌ها و استفاده از مربی هوشمند

## ساخت پروژه اندروید و APK
این بسته سورس Flutter است. برای تولید پوشه‌های پلتفرم اندروید، در ریشه پروژه اجرا کن:

```bash
flutter create . --platforms=android
# در android/app/src/main/AndroidManifest.xml این مجوز را داخل تگ manifest و بیرون از application اضافه کن:
# <uses-permission android:name="android.permission.INTERNET"/>
flutter pub get
flutter analyze
flutter build apk --release
```

خروجی APK:
`build/app/outputs/flutter-apk/app-release.apk`

برای نصب روی گوشی متصل:
```bash
flutter install
```

## اتصال مربی هوشمند
در صفحه خانه روی آیکون تنظیمات بزن و نشانی HTTPS سرور واسط خودت را وارد کن.
اپلیکیشن یک POST با JSON زیر ارسال می‌کند:

```json
{
  "message": "متن پیام کاربر",
  "system": "دستورالعمل مربی",
  "day": 1
}
```

سرور باید پاسخ JSON با یکی از فیلدهای `reply` یا `answer` برگرداند:

```json
{"reply": "پاسخ مربی"}
```

**امنیت:** کلید ارائه‌دهنده مدل را فقط روی سرور نگهداری کن؛ هرگز آن را در اپ اندروید یا مخزن عمومی قرار نده. برای محیط واقعی، احراز هویت کاربر، محدودسازی نرخ درخواست، ثبت حداقلی لاگ، کنترل هزینه و سیاست نگهداری داده را اضافه کن.

## محدودیت‌های این MVP
- اتصال هوش مصنوعی تا زمان تنظیم endpoint سرور، فعال نیست.
- محتوای درس‌ها در این نسخه نقشه راه و توضیحات اولیه است؛ بانک درس‌های علمی، منابع و آزمون‌های معتبر باید در مرحله محتوایی بعدی تکمیل شوند.
- ذخیره‌سازی فعلی محلی و بدون همگام‌سازی ابری است.
- شاخص پیشرفت، شاخص رفتاری ساده است و ادعای سنجش IQ یا تشخیص روان‌شناختی ندارد.
- تاریخ شروع برنامه در این نسخه با شمارنده روز مدیریت می‌شود؛ تقویم شمسی و یادآورهای زمان‌بندی‌شده در مرحله بعد افزوده می‌شوند.
